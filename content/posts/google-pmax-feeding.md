## PMAX 是什麼

成效最大化（Performance Max）是 Google 把搜尋、多媒體、YouTube、Gmail、探索、地圖整合成**單一活動**，由系統自動決定要在哪裡曝光、給誰看、出價多少。

好處是省事、涵蓋面廣。壞處是**你看不到細節，也改不了細節**。

這個特性決定了操作 PMAX 的心態要不同：你不是在調整投放，你是在**準備輸入**。輸入品質決定一切。

## 你真正能控制的四件事

### 一、素材資產群組

這是最重要的一項。

**不要把所有產品線的素材丟進同一個資產群組。** 系統會把它們混在一起用，導致 A 產品的圖配上 B 產品的標題。

正確做法是**依產品線或客群分開建立資產群組**。一個賣男裝也賣女裝的品牌，至少要分兩組。

每組要給滿：

| 資產 | 建議數量 | 注意 |
| --- | --- | --- |
| 標題（短） | 5 則以上 | 每則講不同賣點，不要換句話說 |
| 標題（長） | 3 則以上 | |
| 說明 | 3 則以上 | |
| 圖片（橫式、方形、直式） | 各 3 張以上 | 三種比例都要給，缺了會少版位 |
| 影片 | 至少 1 支 | 沒給的話系統會自動生成，品質通常不好 |
| Logo | 方形＋橫式 | |

**影片那項特別提醒**：如果你不提供，Google 會用你的圖片自動合成一支。那個成品通常很粗糙，但它會被拿去投 YouTube。與其讓系統亂做，不如給一支簡單但正確的。

### 二、目標對象信號

這是一個很容易誤解的設定。

**目標對象信號不是受眾鎖定**——系統不會只投給這群人，它是把這群人當成**學習的起點**。

給得好可以大幅縮短學習期。建議放進去的：

- 你的**既有客戶名單**（最有價值）
- 網站訪客與加購未結帳的再行銷名單
- 高價值客戶的類似受眾
- 與產品高度相關的自訂客群

**不要放太廣泛的興趣類別**，那等於沒給起點。

### 三、商品目錄（電商）

如果你是電商，PMAX 會大量依賴商品資料。目錄的完整度直接影響曝光。

常被忽略的欄位：

- **商品標題**——要包含品牌、品項、關鍵屬性，不要只寫商品名
- **商品描述**——很多人留空或塞了一堆 HTML
- **商品類別**——分類錯會投給錯的人
- **圖片**——白底主圖之外多給幾張情境圖
- **庫存狀態**——沒同步的話會投缺貨商品

我們接手帳戶時，光是把商品標題重寫一遍，就常常能看到明顯改善。

### 四、轉換追蹤與價值

這是最容易出錯、後果最嚴重的一項。

PMAX 完全依賴轉換訊號來學習。如果：

- 轉換沒設定 → 系統不知道什麼是成功
- 設成「加入購物車」而非「購買」 → 系統努力幫你找愛加購但不結帳的人
- 沒傳轉換價值 → 系統會把 NT$300 的訂單和 NT$30,000 的訂單當成一樣

**尤其最後一項**。電商一定要傳實際的訂單金額，否則系統會朝「訂單數量最多」優化，而不是「營收最大」。

## PMAX 不適合的情況

誠實說幾個 PMAX 表現通常不好的場景：

**一、預算太小。** PMAX 涵蓋六個版位，預算被切得很碎。每月低於 5 萬的話，集中做傳統搜尋廣告效率通常更好。

**二、需要嚴格控制品牌詞。** PMAX 會吃掉品牌搜尋流量，讓你的整體數字變好看，但那些人本來就會找到你。如果你想知道 PMAX 的**增量貢獻**，要把品牌詞加進排除。

**三、有嚴格的版位或內容限制。** 醫療、金融這類產業如果對曝光環境有要求，PMAX 的黑箱特性會是風險。

**四、剛開始投放、沒有任何轉換資料。** 系統沒有東西可以學。這種情況先用搜尋廣告累積轉換資料，再上 PMAX。

## 怎麼判斷 PMAX 有沒有效

因為看不到細節，判斷方式要靠對照：

1. **排除品牌詞**，看非品牌的轉換有沒有成長
2. 和**同期的搜尋廣告**比較單次轉換成本
3. 觀察**整體帳戶**的轉換有沒有真的增加，而不是從其他活動搬過來

第三點特別重要。PMAX 常常會「認領」本來就會發生的轉換，讓它自己的數字很好看，但帳戶總量沒變。

## 重點整理

1. 資產群組**依產品線分開**，不要全部混在一起
2. 三種圖片比例都要給，**影片自己準備**
3. 目標對象信號是**起點不是鎖定**，用既有客戶名單最好
4. 電商的**商品標題**值得重寫一遍
5. 一定要傳**轉換價值**，不然系統會優化錯方向
6. 預算低於每月 5 萬、或剛開始沒轉換資料時，先別用 PMAX
