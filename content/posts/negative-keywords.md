## 為什麼這件事這麼重要

我們接手帳戶時最常看到的浪費，就是預算流向完全不相干的搜尋。

賣高價家具的被「二手」「免費」「DIY」吃預算。做企業顧問的被「顧問 工作」「顧問 薪水」吃預算——那些是在找工作的人，不是客戶。

這類浪費在沒整理過的帳戶裡，佔比常常在 **20～40%** 之間。

**修好它不需要加任何預算，也不需要改策略。** 純粹是把漏掉的水堵起來。

## 每週二十分鐘的流程

### 第一步：打開搜尋字詞報告

Google Ads 裡的「搜尋字詞」報告，會列出**實際觸發你廣告的搜尋內容**——這和你設定的關鍵字是兩回事。

時間範圍設「過去 7 天」，排序用「費用」由高到低。

### 第二步：從花最多錢的看起

由上往下看，對每一個問三個問題：

1. 這個人是我的潛在客戶嗎？
2. 這個搜尋的意圖和我的產品一致嗎？
3. 這筆錢花得值得嗎？

任何一題是否定的，就加進否定清單。

**從花最多錢的看起**，因為修一個大的比修十個小的有效。通常看前 20～30 筆就夠。

### 第三步：判斷該加在哪一層

否定關鍵字可以加在三個層級：

| 層級 | 適用 |
| --- | --- |
| **帳戶層級**（共用否定清單） | 永遠不想要的詞，例如「免費」「求職」 |
| **活動層級** | 這個活動不要、但其他活動可能要 |
| **廣告群組層級** | 用來做群組之間的分流 |

**大部分的詞應該加在帳戶層級的共用清單**，這樣新開活動時會自動套用，不用每次重來。

### 第四步：選對否定的比對類型

否定關鍵字也有比對類型，而且邏輯和一般關鍵字不同：

- **否定廣泛比對** `免費` —— 只要搜尋含這個詞就排除（但不含同義詞）
- **否定詞組比對** `"免費 諮詢"` —— 含這個詞組才排除
- **否定完全比對** `[免費]` —— 完全等於這個詞才排除

**多數情況用否定廣泛比對**。它比一般的廣泛比對嚴格得多，不會誤傷同義詞。

要小心的是別否定得太廣。例如做「兒童英語」的把「兒童」設成否定，會把所有相關搜尋都殺掉。

## 一份通用的起始清單

不管什麼產業，這些通常可以先加進帳戶層級：

**求職與內部資訊**
```
求職、應徵、職缺、薪水、面試、工讀、打工、實習
```

**免費與低價意圖**
```
免費、破解、序號、下載、教學、自製、DIY、怎麼做
```

**二手與競品**
```
二手、中古、出清、蝦皮、露天、拍賣、批發
```

**負面與客訴**
```
評價、負評、詐騙、爭議、糾紛、投訴、退費
```

**注意「評價」這個詞要斟酌。** 搜尋「XX 評價」的人很可能正在考慮購買，那是高意圖流量。但如果搜尋的是「XX 詐騙」就不是。這類詞建議用詞組比對精準處理，不要一刀切。

**學術與研究**
```
定義、意思、維基、論文、報告、範例
```

## 進階：用否定做群組分流

否定關鍵字不只用來排除垃圾流量，也可以用來控制流量分配。

假設你有兩個廣告群組：

- A 群組：`[除濕機推薦]` 完全比對，精準文案
- B 群組：`除濕機` 廣泛比對，泛用文案

如果不處理，B 群組會搶走 A 群組的流量。解法是**在 B 群組把「除濕機推薦」設為否定**，強迫那個搜尋只能由 A 群組承接。

這樣每一個搜尋意圖都有明確歸屬，成效歸因也乾淨。

## 幾個容易忽略的地方

**一、Meta 也需要，只是形式不同**

Meta 沒有否定關鍵字，但有受眾排除。邏輯是一樣的：把不會轉換的人排除掉，讓預算集中。

**二、PMAX 的否定要另外設**

PMAX 的否定關鍵字設定位置和一般活動不同，而且限制較多。詳細做法在[PMAX 那篇]({{root}}blog/google-pmax-feeding/)。

**三、否定清單要定期回頭檢視**

產品線變了、市場變了，以前不要的詞可能變成要的。建議每季回頭看一次清單，把過時的移除。

## 重點整理

1. 每週二十分鐘，看**搜尋字詞報告**
2. 從**花最多錢**的看起，看前 20～30 筆
3. 大部分否定加在**帳戶層級共用清單**
4. 預設用**否定廣泛比對**，但小心別設太廣
5. 「評價」這類詞要斟酌，可能是高意圖流量
6. 否定也可以用來做**群組分流**
7. 每季回頭檢視一次清單

這件事沒有技術含量，但它是我們接手帳戶後最先做、也最常見效的動作。
